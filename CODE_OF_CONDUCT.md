# Code of Conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, give and accept constructive feedback, and do
not harass anyone. This applies in issues, pull requests, discussions and anywhere you
represent the project.

## Reporting

Report unacceptable behavior to the maintainer by opening a
[GitHub issue](https://github.com/akshitkhokhani/zero-hour/issues). If the matter is
sensitive and you do not want it public, use a minimal issue asking the maintainer to
contact you, or contact [@akshitkhokhani](https://github.com/akshitkhokhani) through GitHub.

The maintainer will review every report and may remove, edit or reject contributions, or
ban contributors, for behavior that violates this code. Enforcement follows the
Contributor Covenant 2.1 enforcement guidelines.
